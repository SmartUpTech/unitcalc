Essential acceptance contract:

- English (United States), region US, USD and Western digits 0–9 are fresh-install defaults. Language, region and currency are independently selectable.
- Ship all 14 translation choices in the plan, representing 13 languages. Use only native locale-qualified strings.xml files for app-owned translated text, including plurals/arrays. No translator library/API, runtime translation, network lookup or English placeholder files masquerading as complete translations. Use concise, natural, friendly-professional standard language.
- Offer all countries/territories whose currencies the current catalog supports, including countries sharing a currency. Use stable ISO identities, current verified mappings and localized XML names.
- Language applies immediately. Suggest a region only if it is not a common-language match and that language/current-region pair was not previously declined. Short copy: Switch region to Germany? / Resets number format and currency. / Switch / Keep current. Localize the prompt. Preserve pending state across Activity recreation; no repeated launch prompts. See the full state rules in the plan.
- A different region resets number-format customizations, displayed decimal preference to the four-place app default, and preferred currency. Same-region selection preserves overrides. Users can customize separators, grouping pattern, decimal places and currency afterward. Reset to region defaults keeps language and existing saved amounts.
- Preserve existing users' effective settings during a versioned migration, including absent-key defaults. Preserve app-language choices from Android system settings. Never derive region from the application locale.
- Keep canonical calculations/storage, formulas, precision, rounding and rate logic unchanged. Normalize localized input safely and display Western digits. Preserve incomplete edits, cursor/navigation state, saved scenario currencies, converter selections, history, timers and widgets. Never reinterpret an old formatted amount under a new locale.
- Reuse shared settings controls, theme/typography/keypad owners and Graphy primitives. Every primary tool must remain on one non-scrolling screen in the actual available viewport. Do not claim runtime/visual compliance from source inspection.

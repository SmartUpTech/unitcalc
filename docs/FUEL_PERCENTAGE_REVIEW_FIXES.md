# Fuel Efficiency and Percentage review fixes

Applied to `release/v12`, starting at `61aedde5468fa4fd2ebd1fc656d79da41c33c7ed`.

## Changes

- Exposed the shared compact sizing API and declared the fuel Done accessibility resource.
- Supplied explicit layout dimensions for every affected label and result view. Explicitly styled the fuel Material switch and disabled its unused internal On/Off labels; native measurement exposed a null-text crash after the original inflation blockers were fixed.
- Synchronized keypad field references with taps/focus. Back closes the Calculate keypad and returns from Graphy to Calculate. Programmatic focus restoration preserves keypad visibility; hidden fragments disable their Back callbacks.
- Replaced truncating length filters with complete-replacement validation. Oversized pasted values leave the original value intact.
- Added checked/unchecked/disabled semantic colors for Material toggle buttons and palette-aware fuel switch colors. Theme changes also update workspace tabs. Fuel selectors, symbols, suffixes and labels use semantic colors.
- Added fuel history payload version 2 with currency identity, including drafts. Version 1 and legacy drafts remain readable and fall back to the current preference when currency is absent. Restoring history never changes the global preference; Reset starts with the current preference.
- Retained normalized distance and consumption in the authoritative fuel result. Graphy uses km and L/100 km with the `/100` step, includes passengers as an operand, and shows cost per passenger after division. Percentage Increase/Decrease now explicitly combine base and percentage amount; What Percent describes division.
- Distinguished mpg US/Imperial selectors, made fuel volume respect number-format preferences, retained labels during compaction, and measured fit against the visible result/keypad region.

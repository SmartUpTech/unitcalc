# PROJECT GLOSSARY

## GRAPHY
- **Node**: A visual box representing a value or operation.
- **Connection**: The line showing data flow between nodes.
- **Output**: The data structure consumed by the Graphy render layer.

## CALCULATOR
- **Catalog**: The central registry of all converters and tools.
- **Destination**: The target screen or action for a catalog entry.
- **Entry**: A specific tool (e.g., "Length Converter").
- **Section**: A group of entries (e.g., "Common Units").

## UI & THEMING
- **Workspace**: The main tabbed area of the application.
- **Pane**: An XML layout file representing a specific tool's UI.
- **ThemeApplier**: The engine that propagates colors to Views.
- **Semantic Color**: A color defined by its role (e.g., `operator`) rather than value.
